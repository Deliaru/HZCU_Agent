# ADR-0001：采用模型原生校园认知 Agent

| 属性 | 值 |
|---|---|
| 状态 | Accepted |
| 日期 | 2026-07-25 |

## 背景

校园产品需要处理口语、省略、情绪、复合意图、长期目标和快速变化的信息。传统“意图分类—知识库检索—模板回答”只能解决明确事实题，在问题模糊时会频繁要求重述，也不能把政策转化为针对学生的行动建议。

## 决策

采用模型原生 Agent：

- 主模型始终看到原始问题、相关上下文、学生画像和调查证据。
- 模型自主形成多个目标假设并制定调查计划。
- 知识检索只是工具之一。
- 实时来源、结构化查询、比较和校内 API 均通过工具网关接入。
- 证据评价和引用校验约束校园事实。

## 后果

正面：

- 能处理模糊、多轮和复杂问题。
- 可以将事实、影响和建议组合。
- 可随工具扩展到个性化和办事。

代价：

- 评测比 FAQ 命中更复杂。
- 模型、工具、数据和证据需要全链路可观测。
- 延迟与成本高于单次检索生成。
- 必须设置调查预算和故障降级。

## 被否决方案

- 纯向量知识库问答。
- 单一意图分类后的模板回答。
- 只依赖模型内部知识回答校园事实。
