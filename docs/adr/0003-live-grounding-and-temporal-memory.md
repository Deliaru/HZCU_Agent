# ADR-0003：实时官方调查与时间版本记忆共同构成事实基础

| 属性 | 值 |
|---|---|
| 状态 | Accepted |
| 日期 | 2026-07-25 |

## 背景

教学通知、报名窗口和活动状态快速变化；学生手册和政策又具有年级及历史版本。只查询静态知识库会过期，只实时搜索则无法稳定回答历史和复杂政策问题，也会增加延迟与来源负载。

## 决策

采用双通道事实基础：

- 后台持续采集、解析、版本化并建立校园记忆。
- 时间敏感或缓存过期的问题执行查询时实时调查。
- 实时发现的新版本经过校验后自动回写。
- 文档保存发布、生效、失效、观察和新鲜度时间。
- 回答明确标记实时、缓存、历史、降级或冲突状态。

知识库的定位是：

- 历史版本。
- 当前状态缓存。
- 低延迟检索。
- 来源不可用时的透明降级。

## 后果

正面：

- 同时支持“现在怎么样”和“当时适用什么”。
- 避免每次问题完整抓取官网。
- 能追踪政策变化并审计引用。

代价：

- 需要来源 TTL、版本关系和回写质量门槛。
- 需要处理同 URL 内容替换和来源冲突。
- 真正秒级更新仍依赖 Webhook 或事件推送。

## 被否决方案

- 只做周期性向量库更新。
- 每次请求无差别实时爬取全部来源。
- 原地覆盖文档，不保留历史版本。
