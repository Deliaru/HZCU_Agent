# ADR-0002：废止代码侧语义分类路由

| 属性 | 值 |
|---|---|
| 状态 | Superseded |
| 原日期 | 2026-07-25 |
| 废止日期 | 2026-08-03 |

## 背景

早期方案曾考虑让多标签语义信号参与工具候选和检索处理。实际开发表明，这会让有限
标签逐渐变成业务硬门：新问题、新材料或复杂 PDF 很容易被已有分类和筛选规则挡住。

## 当前替代方案

- 模型直接看到用户原始问题、必要会话、已确认画像、当前时间和动态通用工具目录；
- 模型自行理解问题、形成可修正假设、选择工具和材料；
- 代码只执行权限、来源、参数、资源 ID、读取范围和调用预算等通用契约；
- 语义档案若保留，只是同一模型的可修正输出，不参与代码侧工具选择、材料过滤或
  业务优先级；
- 不为语义路由建立分类器、标签集、校准项目或问题专用规则。

## 结果

当前 Agent 遵循 Everything is model 与 Generality & Atomicity。新增业务问题由模型
通过已有通用工具处理；如果现有原子动作确实不足，是否增加新工具由用户决定。
