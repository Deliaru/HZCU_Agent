# ADR-0005：校园事实按来源权威与不可变版本管理

| 属性 | 值 |
|---|---|
| 状态 | Accepted |
| 日期 | 2026-07-25 |

## 背景

校园信息可能被学校、责任部门、学院、教师主页和官方新媒体重复发布。内容可能存在更新、转载、不同适用范围和冲突。仅按语义相似度或发布时间排序会产生错误结论。

## 决策

- 每个来源登记责任部门、权威等级、可见性和新鲜度策略。
- 每个资源保存不可变 DocumentVersion。
- 每条证据携带完整 Provenance。
- 排序综合责任部门、适用范围、时间版本、来源权威和相关性。
- 非官方内容不得单独支持校园政策事实。
- 无法消解的官方冲突必须向用户呈现。

## 后果

正面：

- 可以解释“为什么相信这份材料”。
- 支持不同入学年份和历史政策。
- 错误答案可以追溯到具体来源版本。

代价：

- 来源登记和版本关系需要持续治理。
- 内容抽取必须保留原文定位。
- 运营人员需要处理无法自动消解的冲突。

## 被否决方案

- 只保存最新正文。
- 只按向量分数排序。
- 将官方转载视为独立权威来源。
- 用模型自行裁定无法证明的政策冲突。
