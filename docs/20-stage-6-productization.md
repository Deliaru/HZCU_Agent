## 3. 本地交付方式

首次安装并迁移：

```bash
make api-install
make api-migrate
make web-install
```

终端一启动真实模型 API：

```bash
make api-real API_PORT=18000 MODEL_CONFIG=API.txt
```

终端二启动 Web：

```bash
make web-dev API_PORT=18000 WEB_PORT=13000
```

浏览器访问 `http://127.0.0.1:13000/`。`API.txt` 只在启动时读取到进程内存，不会被
复制为 `.env`，也不会在日志中输出。端口参数可以按本机占用情况修改，但 Web 的
`API_PORT` 必须与 API 一致。
