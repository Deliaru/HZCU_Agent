# 两套问答主题的排版规范

## 本次处理

入口为 `apps/web/styles/agent-readability.css`，在旧主题样式之后加载，仅约束
`.stage6-shell` 与 `.congyu-agent` 的阅读区域；简洁主题的共享导航覆盖
所有 `.app-chrome` 页面，避免问答、悬赏、来源、后台切页时变回旧导航。
不修改宣传页、动画或数据库。

- 正文、输入框：16px（1rem），正文行高 1.8，输入行高 1.6。
- 常规操作与推荐问题：14px；辅助标签、来源元数据与桌面免责声明：12px。
- 阅读文字使用 `--font-ui`；代码和追溯标识允许等宽字体。
- 功能标题统一 UI 字体、700 字重；角色欢迎页的大标题保留装饰性宋体。
- 小字使用正常字距和常规字重，不通过缩放文字实现紧凑布局。
- 简洁欢迎页取消右侧装饰和空证据栏；内容以 860px 为上限居中，推荐问题
  改为独立卡片，桌面输入紧接推荐问题，短屏整体可滚动。进入会话后恢复证据栏。
- 保留移动端固定输入区和原有键盘安全边距；移动端不显示输入框免责声明。

## 为什么“字体设置一样”仍不一样

基础变量不代表最终样式相同：角色主题有显式的 `Noto Serif SC, serif` 标题，
简洁主题部分标签另用 `--font-mono`。多层样式与媒体查询中还存在 7–11px、
不同字重和字距。此前桌面与移动端的字体平滑配置也不一致。
本次以最后加载的、限定作用域的阅读规范统一关键阅读区域，避免影响其他页面。

字体栈仍使用设备安装的字体，不保证 Windows、macOS、Linux 逐像素一致。
字体未安装时会继续回退，只有常规/粗体的字体也不能精确表达 650、800 等字重。
因此不要把系统字体栈一致误认为实际字体文件一致。

若后续要求跨设备同字形，可引入经过许可的自托管简体中文 WOFF2 字体，
按 Unicode 分段并仅提供实际需要的 400/700 字重，设置 font-display: swap。
这需要另行评估字体许可、中文字体体积与首屏加载；本次不接入外部字体服务。

- 开发者工具检查 computed font 与实际 rendered fonts，而非只看变量名称。
