# 当前 Agent 工具与应用 API

| 属性 | 值 |
|---|---|
| 文档编号 | SPEC-API-001 |
| 状态 | Current Implementation Reference |

## 1. 范围

本文只记录代码当前提供的 Agent 工具与 Web API，不规划未来接口。新增工具、个人
数据接口、管理功能或校园业务写操作必须先由用户确认。

## 2. 工具设计原则

- 工具通用且原子，只负责搜索、检查、查找、读取或访问已经登记的官方来源。
- 模型负责理解问题、选择材料、决定翻阅位置、解释表格并形成结论。
- 代码只校验参数、权限、资源范围、调用预算和返回结构，不按业务主题替模型路由。
- 搜索结果是候选材料；模型可以继续检查、文内查找和按页/块阅读。
- 工具结果携带来源、版本、时间和可见性信息，供回答建立证据关系。

## 3. 当前 Agent 工具

| 工具 | 原子能力 | 主要结果 |
|---|---|---|
| `search_campus_memory` | 用一个模型生成的查询搜索当前校园镜像 | 候选标题、片段、来源与 `document_version_id` |
| `inspect_campus_document` | 查看一份候选材料的结构目录 | 页、文本块或其他可读取 locator |
| `find_in_campus_document` | 在指定材料内查找模型给出的表达 | 命中位置与短上下文 |
| `read_campus_document_locator` | 读取一个完整页或文本块 | 连续原文及通用布局坐标（如有） |
| `read_campus_document_segment` | 从指定 offset 读取一段连续原文 | 可继续翻阅的文本段与位置 |
| `search_official_live` | 查询已登记的公开官方网页 | 当前网页证据与访问记录 |
| `search_campus_notices_live` | 在登录且路由可用时查询校园通知 | Campus 只读证据与访问记录 |

这套工具统一处理培养方案 PDF、扫描材料、HTML 通知、新闻和其他已解析材料。工具
名称、参数或排序中不加入“培养计划”“评奖评优”等业务专用分支。

## 4. 通用结果与错误

工具结果至少说明：

- 调用是否成功；
- 实际读取到的内容；
- 来源 URL、标题、版本和适用时间（可取得时）；
- 是否还有可继续读取的位置；
- 失败属于参数、权限、网络、来源还是解析问题。

零命中只表示本次查询没有取得证据，不能被改写成“学校不存在该信息”。实时来源
失败也不能删除本地镜像中的既有材料。

## 5. 当前 Web API

所有应用接口位于 `/api/v1`。

| 资源 | 当前接口范围 |
|---|---|
| 健康 | 服务、模型和依赖状态 |
| 会话 | 创建、列表、详情、改名与删除 |
| 消息与任务 | 提问、任务状态、SSE 事件、取消与重试 |
| 回答与证据 | 回答详情、证据、来源打开、重新核验与反馈 |
| 画像 | 查看、更新、按属性删除、建议确认或拒绝 |
| 待办 | 列表、新增、完成、更新与删除 |
| 身份 | 匿名设备、可选 CA、访客数据合并与清理 |
| 来源 | 来源账本、状态、版本和告警读取 |
| 运营 | 已实现的管理员 overview、feedback 和 task-health 只读页面 |

会话、画像、待办、反馈和回答按 `ProductSubject` 隔离。匿名试用是否可读取 Campus
本地镜像由部署配置决定，但不因此获得 Campus 实时工具或其他主体的数据。

## 6. 数据写入边界

用户当前可以写入的仅是本产品自身数据，例如消息、会话名称、已确认画像、手动待办
和反馈。Agent 不提供选课、报名、申请、提交、撤回、评价或预约等校园业务写操作。

实时官方证据的镜像回写由服务端在已登记来源范围内处理，不是模型可以自由选择任意
URL 或数据库的通用写入工具。

## 7. 兼容与错误恢复

- 创建消息使用 `client_message_id` 保持会话内幂等。
- 任务状态支持取消、重试和服务重启后的明确恢复结果。
- SSE 断开后，Web 可以通过任务与回答接口恢复最终状态。
- API 路径保持 `/api/v1`；需要破坏性修改时再按实际实现同步本文。

接口细节以当前 FastAPI 路由和 Schema 为最终依据。本文与代码不一致时，先按实际
功能修正文档，不把差异解释为必须开发的新接口。
