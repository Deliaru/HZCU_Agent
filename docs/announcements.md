# 公告系统

- 管理入口：后台 → 公告管理。管理员发布纯文本标题、正文，可撤回，不覆盖修改已发布内容。
- 用户接受当前版本隐私声明后才请求公告；未同意时不请求、不展示公告。
- 每次进入页面、路由切换或窗口重新获得焦点时读取未读公告，按发布时间逐条显示。
- 弹窗必须勾选已阅读并确认，服务器保存成功后才关闭；Escape 与背景点击不会确认。
- 已读记录按产品身份保存：匿名用户按设备 Cookie，登录用户按账号。清除 Cookie 或更换
  身份可能重新提示；不是跨设备匿名跟踪。撤回公告不再进入未读列表。
- 公告加载失败不阻断校园功能，提供重试；确认失败保留当前公告并提示重试。
- 发布、撤回仅限管理员，写操作受 CSRF 保护并记录安全审计。用户已读写入为幂等操作。
- 正文不渲染 HTML 或 Markdown，避免脚本注入。标题上限 160 字符、正文上限 20000 字符。
