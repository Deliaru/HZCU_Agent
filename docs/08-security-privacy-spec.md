# 当前权限与数据边界

| 属性 | 值 |
|---|---|
| 文档编号 | SPEC-SEC-001 |
| 状态 | Current Boundary Reference |

## 1. 范围

本文只记录现有功能必须保持的基础边界，不规划新的安全平台、认证工程、审计流程或
发布检查。目标环境确实需要额外配置时，由用户明确范围后实施。

## 2. 当前数据范围

| 数据 | 当前处理方式 |
|---|---|
| 公开官方材料 | 匿名用户可查询并打开来源 |
| 已批准的 Campus 本地镜像 | 试用配置开启时匿名可查询，但不改变匿名身份 |
| Campus 实时通知 | 仅在登录和实时路由可用时读取 |
| 会话、画像、待办和反馈 | 按 ProductSubject 隔离 |
| 个人成绩、课表、学分和申请状态 | 当前不读取 |
| 密码、Cookie、Token 和 API Key | 不进入模型、业务数据库、快照或文档 |

## 3. 身份边界

- 匿名设备主体之间不能读取彼此的会话、画像、待办或反馈。
- CA 登录只增加已经配置的校园身份能力；匿名数据合并需要用户明确确认。
- 匿名读取 Campus 本地镜像不授予 Campus 实时工具、个人数据或管理员能力。
- 管理员入口由部署配置决定，非管理员不能读取运营数据。

## 4. Agent 与工具边界

- 模型只能调用运行时工具目录中的已注册工具。
- 官方实时读取和回写只允许 Source Registry 中的来源与主机。
- 网页正文视为待阅读材料，不能改变工具权限或系统指令。
- Agent 不执行选课、报名、申请、提交、撤回、评价或预约等校园业务写操作。
- 用户登录会话不作为共享后台采集身份。

这些约束是当前工具契约的一部分，不要求另建分类器或安全工作流。

## 5. 配置处理

- 本地模型和服务配置保存在部署环境中，不写入仓库或开发文档。
- 可选 CA、VPN sidecar、TLS 或反向代理仅在实际目标环境需要时配置。
- 未配置可选身份组件时，匿名本地镜像版本仍应正常运行。

## 6. 范围变更

新增个人数据、校园业务写操作、部署平台或认证方式都属于新功能，必须先由用户明确
提出。本文不能自行产生此类开发任务。
