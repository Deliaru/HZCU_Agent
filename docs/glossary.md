# 术语表

| 术语 | 定义 |
|---|---|
| Agent | 能理解目标、制定计划、调用工具、评价结果并完成任务的模型驱动系统。 |
| 模型原生 Agent | 以模型的语义理解和动态规划为核心，而非将模型附加到固定客服流程上的 Agent。 |
| 主协调 Agent | 维护用户目标、上下文、调查计划、证据和最终回答的核心 Agent。 |
| Semantic Perception | 对原始问题、上下文和画像进行多假设语义理解的模型能力。 |
| SemanticDossier | 语义感知输出的结构化档案，包含目标假设、隐含需求、实体、风险和所需证据。 |
| GoalHypothesis | Agent 对用户真实目标的一种可修正解释；同一任务可以同时存在多个。 |
| 分类器 | 产生领域、意图、时效等辅助信号的模型模块，不直接决定答案。 |
| 硬路由 | 单一标签直接决定固定后续流程；本项目不采用。 |
| Dynamic Planner | 根据原始问题、语义档案、工具和已有证据动态生成调查计划的模型能力。 |
| 调查轮 | Planner 调用一组工具并由证据评价器检查结果的一次循环。 |
| Tool | Agent 访问检索、官网、API、结构化数据或确定性计算的受控接口。 |
| Tool Gateway | 负责工具 Schema、权限、域名、凭据、预算、超时和审计的服务边界。 |
| Source Registry | 记录允许访问的数据源、责任部门、权威、获取方式和 TTL 的来源登记表。 |
| 校园记忆 | 经验证的校园原文版本、结构化实体和检索索引；不是 Agent 的唯一知识来源。 |
| 校园世界模型 | 对当前学期、事件、政策、课程、人员和关系的持续更新表示。 |
| RAG | 检索增强生成。本项目将它作为校园记忆查询能力之一。 |
| 混合检索 | 组合中文全文、向量、结构化字段、权威和时间排序的检索。 |
| 实时调查 | 用户提问时直接查询允许的官方网页或 API。 |
| 持续采集 | 后台通过事件、API 或轮询不断更新校园信息。 |
| 查询时回写 | 将实时调查发现的新官方版本经过校验后写入校园记忆。 |
| SourceDefinition | 一个受治理数据源的配置实体。 |
| SourceResource | 一个稳定可寻址的网页、API 对象或附件。 |
| DocumentVersion | SourceResource 在某一时刻的不可变内容版本。 |
| Provenance | 来源、资源、版本、发布单位、时间和内容哈希组成的出处信息。 |
| Evidence | 当前任务中可支持或反驳某个主张的带出处材料。 |
| Evidence Workspace | 当前 Agent 任务的结构化证据集合。 |
| Evidence Critic | 判断证据是否相关、充分、新鲜、适用或冲突的模型能力。 |
| Claim | 回答中可被验证的事实主张。 |
| Citation | Claim 到 Evidence 和官方原文的用户可见引用。 |
| Groundedness | 回答中的事实是否由证据支持。 |
| Authority Level | 来源在特定信息领域的权威等级。 |
| AudienceScope | 政策或通知适用的学生类型、年级、学院、专业和其他条件。 |
| TTL | 某条缓存或证据被视为足够新鲜的有效时长。 |
| `published_at` | 官方发布内容的时间。 |
| `effective_from/to` | 政策或状态的生效区间。 |
| `observed_at` | 系统实际读取该内容的时间。 |
| `fresh_until` | 当前证据可被视为新鲜的截止时间。 |
| 当前状态 | 在特定时刻仍有效或开放的校园事实。 |
| 历史版本 | 已不再是当前版本，但对往届或历史查询仍有价值的内容。 |
| 学生画像 | 用户确认或允许推断的年级、专业、目标、兴趣和偏好。 |
| 确认属性 | 用户明确提供或确认的画像事实。 |
| 推断属性 | 模型从对话中推测、带置信度且可被用户否定的画像属性。 |
| 工作记忆 | 当前任务的临时问题、假设、计划和证据。 |
| 对话记忆 | 用于恢复多轮指代和连续目标的相关历史。 |
| 任务记忆 | 需要跨轮继续处理的明确目标、计划或待办。 |
| 主动服务 | 系统根据校园变化和学生画像主动生成相关信息或待办。 |
| 最小澄清 | 只有一个关键缺口会实质改变结果时，询问最少必要信息。 |
| 答案优先 | 在安全可行时先提供帮助和合理假设，而不是先阻断式追问。 |
| 透明降级 | 实时或工具失败时明确说明使用的缓存、历史信息和局限。 |
| Model Gateway | 屏蔽模型供应商差异并实施数据、成本和重试策略的统一接口。 |
| Prompt 版本 | 可追踪的系统指令和结构化输出约定版本。 |
| 委托令牌 | 代表当前用户权限的短期服务端凭据引用，模型不能读取真实值。 |
| Public | 可公开访问的校园信息。 |
| Internal | 仅校内授权主体可访问的信息。 |
| Personal | 与具体用户关联的课表、学分或业务状态。 |
| Restricted | 密码、Token、验证码和密钥等不得进入模型或普通存储的数据。 |
| SLO | 对可用性、延迟、新鲜度和正确性设定的服务目标。 |
| ADR | 记录关键架构决策、原因、后果和替代方案的文档。 |
| 需求追踪矩阵 | 将产品需求映射到设计、阶段和测试的表。 |
