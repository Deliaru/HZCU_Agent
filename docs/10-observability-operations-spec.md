# 当前诊断与运行参考

| 属性 | 值 |
|---|---|
| 文档编号 | SPEC-OPS-001 |
| 状态 | Current Diagnostic Reference |

## 1. 范围

本文只记录现有系统如何帮助定位实际运行问题，不规划指标平台、SLO、告警工程、容量
项目或发布流程。

## 2. 当前可用信息

- `request_id`、`conversation_id` 和 `task_id` 用于串联一次问答；
- 任务状态和 SSE 事件说明当前处理阶段；
- 工具调用记录说明调用了什么、是否成功和取得哪些证据；
- 回答保存模型、工具、来源和证据关系；
- Source Registry 记录来源同步状态、最后成功时间和错误；
- 服务日志用于查看 API、模型、数据库、同步和 Web 代理错误。

这些信息用于排错，不要求建设新的看板或统计项目。

## 3. 常见运行问题

### 后台任务详情

运行监测的最近任务可逐条打开详情，按任务关联展示用户原始提问、模型最终回答、
模型名称、状态与错误，以及已持久化的模型/工具执行阶段和耗时。
材料列表展示该回答保存的检索证据（标题、来源、原文链接、摘要、文档版本 ID）。
这些材料不代表所有检索候选；未保存的中间输出和模型内部思维不作推断或补写。
没有回答或执行记录的历史、失败及进行中任务明确显示缺失状态，并支持刷新。
详情仅管理员可读，访问写入管理审计；复用现有数据库，不新增或替换镜像库。

| 问题 | 优先检查 |
|---|---|
| Web 无法连接 Agent | API 进程、Web API 地址和代理路径 |
| 模型未配置 | provider、base URL、模型名和 API Key 是否在部署环境生效 |
| 来源账本 404 | `/api/v1` 路径和 Web 代理配置 |
| 匿名无法查询校园镜像 | Pilot 镜像开关和实际 SQLite 路径 |
| 回答缺少材料 | 搜索结果、文档版本质量状态和模型是否继续翻阅 |
| 重启后数据消失 | 启动前后是否使用同一 SQLite 与 snapshots 目录 |
| Campus 实时读取失败 | 登录状态以及 direct/VPN 路由是否实际启用 |

## 4. 数据保留与恢复

当前持久化对象是 SQLite 文件和 snapshots 目录。部署或重启时保持二者路径不变。
现有备份/恢复命令可以在用户需要时使用，但不构成独立验收项目。

## 5. 变更处理

- 功能或部署错误直接修复；
- 实际日志不足以定位问题时，再补充最小必要诊断；
- 不因尚未发生的规模、性能或安全场景提前建设平台；
- 新运营能力、新报表或新流程必须先由用户确认。

实际启动和故障处理命令见
[`21-pilot-demo-runbook.md`](21-pilot-demo-runbook.md)。
